В моём эксперименте Release оказался быстрее Debug примерно в 7,7 раза

## Что я обнаружил при сравнении il

В Debug есть инструкции nop которых нет в Release. В Release стало меньше лишних операций с локальными переменными например в Add() результат уже не сохраняется в переменную. Количество IL-инструкций в методе Add() изменилось с 10 до 4



## Ответы на контрольные вопросы

1. il - это промежуточный код, в который компилируется C#. Он нужен, чтобы программа не зависела от процессора из il уже при запуске получается машинный код под конкретный компьютер.

2. В .dll лежит il и метаданные, поэтому по ним можно восстановить код похожий на исходный.

3. В Debug есть nop лишние локальные переменные и stloc/ldloc, а ещё br.s. В Release всего этого нет в Add() осталось 4 инструкции вместо 10.

4. В Release компилятор оптимизирует код и убирает лишнее поэтому он выполняется быстрее. У меня он быстрее примерно в 7,7 раза.

5. Потому что строки лежат в .dll как обычный текст без шифрования. Я нашёл их в HEX-редакторе, так что любой может их прочитать.
